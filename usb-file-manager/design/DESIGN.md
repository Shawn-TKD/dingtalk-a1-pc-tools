# A1 文件空间

内置 Image Gen 生成的完整界面概念为 `concept.png`（1536×1024）。实现使用 React + Vite 和本地 Python USB 后台，不把设计图当页面。

白色主内容、#f7f8fa 侧栏、#182022 正文、#14786c 强调色、细灰分隔线。侧栏约 20%，主区间距 32–40px；标题 28–30px、正文 14–16px、按钮 14px。Segoe UI / Microsoft YaHei 系统字体。8px 控件圆角，无大卡片网格或装饰图片。图标使用细线文件夹、硬盘、音频、USB、刷新、搜索、上传。

组件：Sidebar、DeviceStatus、FileBrowser、FileTable、CreateFolderDialog、TransferStatus。真实文件和连接状态由接口提供，不使用模拟录音或虚构空间。

允许文案：A1 文件空间、USB 本地文件管理、设备存储、录音目录、个人文件、连接设备、刷新、名称、类型、大小、操作、搜索当前目录、新建文件夹、上传文件、设备目录只读；上传仅限个人文件夹、所有文件在本机处理，不上传云端。

必要状态扩展：连接后显示真实文件行、电量/空间；上传/校验进度；USB 模式切换确认；首次创建个人目录；文件不存在、断连、无权限、重名等真实错误。空状态与概念一致。手机版侧栏折为顶栏导航、工具栏换行，保持表格为行列表。程序分区不在网页暴露。
